# Riego Paltos

App web para programar el riego de paltos con microaspersión: qué sectores regar cada día, en qué orden y por cuánto tiempo, según la ETo (FAO-56) y el suelo.

**Abrir la app:** https://palacios456.github.io/riego-paltos/

- Los datos de cada predio se guardan solo en el dispositivo de quien los ingresa.
- ETo diaria desde Open-Meteo, con corrección mensual calibrada con estaciones INIA.
- En iPhone: abrir en Safari → Compartir → «Agregar a inicio».

Proyecto de estudiantes de Agronomía PUCV (Agreen Consultores). Este repositorio contiene solo la versión publicada de la app.
